Everything above, in one window

  • Open any tvs_*.itd, choose the division, press Analyse: about one second for 2×2×2.
  • Criteria as PASS, FAIL, WARN or N/A, with the numbers behind each.
  • Ways it opens: click one and drag Pull to slide it out along its own direction.
  • Verify by sliding runs the independent check on the selected group.
  • Disassembly plays the take-apart. Orange: moving. Red: folded. Yellow: too thin.

Tables for the whole sweep: python make_tables.py

The analyser is part of the Qt app: a button Analyse puzzle in the main window opens it. It uses the same code as the command line and the table generator, so what is on screen is exactly what is in the tables.
